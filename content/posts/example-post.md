A post is one markdown file in `content/posts/` with a `title`, a `date` and a
one-sentence `description`. The index sorts by date, newest first, and the
description is what appears under the title there.

## Headings work as they do everywhere else

The body uses the same prose styles as the project pages: `code`, **emphasis**,
lists, blockquotes, and tables all render here without any extra markup.
